# SCIgen - OpenAlex Dataset Generator

This repository contains a fork of the famous **SCIgen** (Automatic Computer Science Paper Generator) codebase, adapted to run on modern Perl installations and modified to generate synthetic research datasets matching the **OpenAlex** schema format in CSV.

## Dependencies

Before running the code, ensure the following packages are installed on your system:
- **Perl** (with `FindBin` and `Getopt::Long` standard modules)
- **LaTeX** / **BibTeX** (e.g., `texlive-base`, `texlive-latex-extra`, `texlive-fonts-recommended`, `texlive-publishers`)
- **Gnuplot**
- **GraphViz**
- **Ghostscript** (for PDF/PS conversion)

## Running the Original SCIgen

To generate a full PDF/PS paper:
```bash
perl make-latex.pl --file paper.ps
```

## OpenAlex Dataset Generator

We introduced a dataset generator script, `generate_openalex.pl`, which produces synthetic papers (titles, abstracts, and keywords) structured to match the OpenAlex schema.

### Usage

```bash
perl generate_openalex.pl --count <number_of_papers> --out <output_csv_file>
```
*Example:*
```bash
perl generate_openalex.pl --count 100 --out dataset.csv
```

### IMRaD Abstract Structure Generation

To make the generated papers serve as a realistic null model for processing OpenAlex datasets, we programmatically construct the abstracts using the standard **IMRaD** (Introduction, Methods, Results, and Discussion) structure by combining specific grammar rules from `scirules.in`:

1. **Introduction (I)**:
   - Generated by combining `SCI_INTRO_A` (introductory hook) and `SCI_INTRO_THESIS` (thesis overview/proposition).
2. **Methods (M)**:
   - Formed by generating two sentences from `SCI_ABSTRACT_A` (describing the methodology/approach).
3. **Results (R)**:
   - Formed by generating two sentences from `EVAL_ANALYZE_ONE` (describing findings, evaluation anomalies, or observations from the evaluation section).
4. **Discussion/Conclusion (D)**:
   - Formed by combining `CONCL_INTRO` (summary of contributions) and `CONCL_CONCL` (future work and concluding outlook).

The output text undergoes post-processing to strip LaTeX syntax (such as section headings, figures, math symbols, and citation tags), normalize whitespace, and correct punctuation formatting (e.g., removing duplicate periods).
